# invariantbotpy

ИИ-бот для Telegram на Python, который использует локальную LLM через [Ollama](https://ollama.com/)
для управления групповыми чатами: автоматическая модерация сообщений (спам, оскорбления, флуд и т.п.)
и обычный чат с ИИ по запросу. Бота можно подключить сразу к нескольким чатам — настройки
(правила, авто-модерация, предупреждения) хранятся отдельно для каждого чата в SQLite.

## Возможности

- **Авто-модерация группы силами ИИ.** Каждое сообщение в подключённом чате отправляется в Ollama
  вместе с правилами чата; модель решает, нарушено ли правило и какое действие применить:
  `none` / `delete` / `warn` / `mute` / `kick` / `ban`.
- **Предупреждения с накоплением.** При достижении лимита предупреждений (по умолчанию 3)
  пользователь автоматически мьютится.
- **Ручные команды модерации** (`/mute`, `/unmute`, `/kick`, `/ban`, `/warns`, `/resetwarns`) —
  для администраторов чата, ответом на сообщение нарушителя.
- **Чат с ИИ.** В личных сообщениях, а также по упоминанию бота или ответу на его сообщение
  в группе — бот отвечает через Ollama. Есть команда `/ask` для разового вопроса.
- **Настройка на чат.** Каждый чат подключается отдельно (`/connect`), у каждого свои правила
  (`/rules`) и переключатель авто-модерации (`/automod on|off`).
- Значения по умолчанию (лимит предупреждений, время мьюта, модель Ollama) задаются через `.env`.

## Требования

- Python 3.11+
- Установленный и запущенный [Ollama](https://ollama.com/download) с загруженной моделью
  (например `ollama pull llama3.1`)
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather)

## Установка (без Docker)

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# отредактируйте .env: впишите TELEGRAM_BOT_TOKEN и свой Telegram user id в SUPERADMIN_IDS

ollama pull llama3.1   # один раз, если модель ещё не загружена
ollama serve           # если Ollama не запущен как сервис

python main.py
```

## Установка через Docker Compose

```bash
cp .env.example .env
# отредактируйте .env

docker compose up -d --build
docker compose exec ollama ollama pull llama3.1
```

Бот подключится к сервису `ollama` внутри docker-сети автоматически (`OLLAMA_HOST=http://ollama:11434`).

## Переменные окружения (`.env`)

| Переменная            | Описание                                                        | По умолчанию              |
|-----------------------|------------------------------------------------------------------|----------------------------|
| `TELEGRAM_BOT_TOKEN`  | Токен бота от @BotFather                                          | —, обязательна             |
| `OLLAMA_HOST`         | URL сервера Ollama                                                | `http://localhost:11434`   |
| `OLLAMA_MODEL`        | Модель Ollama по умолчанию                                        | `llama3.1`                 |
| `SUPERADMIN_IDS`      | Telegram user id владельцев бота (через запятую), для `/setmodel` | —                           |
| `DB_PATH`             | Путь к файлу SQLite с настройками чатов                          | `data/bot.db`               |
| `WARN_LIMIT`          | Сколько предупреждений до автоматического мьюта                  | `3`                         |
| `MUTE_MINUTES`        | Длительность мьюта в минутах                                      | `60`                        |

## Как подключить бота к чату

1. Добавьте бота в группу.
2. Выдайте ему права администратора: удаление сообщений, ограничение участников (мьют/бан/кик).
3. Выполните `/connect` в чате (от имени администратора) — это включит ИИ-модерацию.
4. Задайте правила чата: `/rules Запрещены реклама, оскорбления, флуд и NSFW-контент.`
5. При необходимости отключите/включите авто-модерацию командой `/automod on|off` или
   полностью отключите её через `/disconnect`.

## Команды

| Команда                | Кто может                | Описание                                              |
|-------------------------|--------------------------|--------------------------------------------------------|
| `/start`, `/help`       | все                       | Справка по боту                                         |
| `/connect`              | админ чата                | Подключить чат к ИИ-модерации                           |
| `/disconnect`           | админ чата                | Отключить ИИ-модерацию                                  |
| `/automod on|off`       | админ чата                | Включить/выключить авто-модерацию                       |
| `/rules <текст>`        | админ чата                | Задать правила чата для ИИ                              |
| `/status`               | все                       | Показать текущие настройки чата                         |
| `/warns`                | все (ответом на сообщение)| Показать число предупреждений пользователя              |
| `/resetwarns`           | админ чата (ответом)      | Сбросить предупреждения пользователя                     |
| `/mute [минуты]`        | админ чата (ответом)      | Замьютить пользователя                                   |
| `/unmute`               | админ чата (ответом)      | Снять ограничения с пользователя                         |
| `/kick`                 | админ чата (ответом)      | Удалить пользователя из чата (может вернуться)           |
| `/ban`                  | админ чата (ответом)      | Забанить пользователя навсегда                           |
| `/ask <вопрос>`         | все                       | Разовый вопрос к ИИ                                      |
| `/setmodel <модель>`    | superadmin бота           | Сменить модель Ollama на лету                            |

## Архитектура проекта

```
main.py                     — точка входа, регистрация хэндлеров
bot/config.py                — загрузка настроек из окружения
bot/storage.py                — SQLite: настройки чата, предупреждения
bot/ollama_client.py          — обёртка над Ollama (чат и модерация в формате JSON)
bot/moderation.py             — логика применения решений ИИ-модератора
bot/permissions.py            — проверка прав администратора чата
bot/handlers/commands.py      — команды бота
bot/handlers/messages.py      — обработка обычных сообщений (модерация + чат с ИИ)
bot/handlers/errors.py        — глобальный обработчик ошибок
```

## Ограничения и рекомендации по безопасности

- Модель может ошибаться (ложные срабатывания/пропуски) — начинайте с мягких правил и
  проверяйте лог решений в первые дни работы бота.
- Боту нужны реальные права администратора в Telegram-группе — выдавайте их только
  доверенным ботам и ограничивайте набор прав необходимым минимумом (удаление сообщений,
  ограничение участников), без права менять администраторов чата.
- Никогда не публикуйте `TELEGRAM_BOT_TOKEN` и файл `.env` в репозитории (они уже добавлены
  в `.gitignore`).
